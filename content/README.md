# 콘텐츠 편집 안내

`learn/` 폴더의 `.md` 파일이 고객 앱 **그린리모델링 알아보기** 카드가 됩니다. 개발자 없이 수정할 수 있어요.

- 파일 이름 앞 숫자(`01-`, `02-` …) 순서대로 카드가 놓입니다.
- 맨 위 `---` 사이 머리말:
  - `title` 카드 제목, `emoji` 아이콘, `summary` 한 줄 요약
  - `sources` 출처 목록 (카드 맨 아래 작게 표시)
  - `needsReview: true` 이면 화면에 "출처 확인 중" 표시가 붙습니다. 수치·출처를 확인한 뒤 `false` 로 바꿔주세요.
- 본문은 일반 마크다운입니다. (`## 소제목`, `- 목록`, `**굵게**`)
- 확정되지 않은 할인율·지원금액을 약속하는 표현은 쓰지 않습니다.
