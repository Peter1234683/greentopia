# Green Topia final

그린토피아 최종 시연용 앱 2종입니다. 이웃 건물의 그린리모델링 공사 수요를 묶어 공동견적·경쟁입찰로 공사비를 낮추는 서비스입니다.

| 파일 | 내용 |
| --- | --- |
| `index.html` | 두 앱으로 들어가는 시작 화면 |
| `user.html` | **사용자 앱 (건물주용)**: 건물 등록 → AI 이웃 매칭 → 공동견적 비교 → 지원제도 확인 → 참여 확정 → 진행 상황·후기 |
| `partner.html` | **파트너 앱 (시공업체용)**: 업체 등록·인증 → 입찰 가능한 공동공사 → 입찰서 작성 → 낙찰 → 건물별 시공 관리 → A/S·후기·정산 |

## 실행 방법

설치할 것이 없습니다. `index.html`(또는 각 앱 파일)을 브라우저에서 열면 됩니다. 모바일 화면(폭 390px) 기준으로 만들었습니다.

GitHub Pages를 켜면(Settings → Pages → Branch: `main`) 웹 주소로도 열 수 있습니다.

> 화면의 업체 입찰가, Cluster 번호, 적합도 점수, 후기, 지원사업 내용 등 모든 수치와 사례는 시연용 가상 예시입니다.
